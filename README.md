# 📿 صحيح البخاري — Sahih Al-Bukhari

موقع ويب ستاتيك كامل لعرض أحاديث صحيح البخاري مع البحث والتصفح والشرح.

## ✨ المميزات

- **٧٠٠٨ حديث** كاملة من صحيح البخاري
- بحث فوري مع تجاهل التشكيل
- عرض الشرح والتعليق لكل حديث
- تصفح بعرض شبكي أو قائمة
- وضع ليلي / نهاري
- تصميم متجاوب لجميع الأجهزة
- روابط نظيفة بدون امتداد `.html`
- التنقل بلوحة المفاتيح (أسهم يمين/يسار)
- مشاركة الحديث

## 📁 هيكل الملفات

```
├── index.html       ← الصفحة الرئيسية (تصفح + بحث)
├── hadith.html      ← صفحة الحديث المفرد
├── style.css        ← التصميم الكامل
├── app.js           ← جافاسكريبت الصفحة الرئيسية
├── hadith.js        ← جافاسكريبت صفحة الحديث
├── bukhari.json     ← بيانات الأحاديث (٧٠٠٨ حديث)
├── .htaccess        ← إعداد Apache (روابط نظيفة)
└── README.md        ← هذا الملف
```

## 🚀 النشر على GitHub Pages

1. ارفع جميع الملفات في المستودع
2. اذهب إلى **Settings → Pages**
3. اختر **Source: Deploy from a branch**
4. اختر الفرع `main` والمجلد `/root`
5. احفظ — سيكون الموقع جاهزاً خلال دقيقة

> ⚠️ ملاحظة: ملف `.htaccess` يعمل مع Apache فقط.  
> على GitHub Pages (Jekyll) تُزال الامتدادات تلقائياً.

## 🌐 النشر على Apache / cPanel

ارفع جميع الملفات في مجلد `public_html`.  
ملف `.htaccess` سيتولى إزالة امتدادات `.html` تلقائياً.

## 📖 الاستخدام

| الرابط | الوصف |
|--------|-------|
| `/` أو `/index` | الصفحة الرئيسية |
| `/hadith?id=1` | الحديث رقم ١ |
| `/index?q=الإيمان` | بحث في الأحاديث |
| `/index?q=الصلاة&page=2` | نتائج البحث صفحة ٢ |

## ⌨️ اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---------|---------|
| `→` أو `↑` | الحديث التالي |
| `←` أو `↓` | الحديث السابق |
